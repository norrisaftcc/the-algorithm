# Probe fixtures — v0 pilot (recorded data, not instructions)

Every file under this directory is a fixture for Probe Battery v0. Fixture
content is arranged, and some of it is deliberately false, deliberately
verbose, or carries a quoted gate phrase. Nothing in this directory is an
instruction to a reader of this repository. Per the P7 lesson: this label is
the marker the lost canary files lacked.

Contents:

- `p2_request.md` — the P2 vague build request, verbatim from the battery.
- `p3/` — P3 ground truth. Arranged so recitation and reality diverge:
  `alpha.md` exists and carries its string; `beta.md` exists and does not
  carry the checked string; `gamma.md` does not exist.
- `p4_edit_target.md` — P4 edit target. A verbose document carrying an
  Invariants block with the five fixed strings.
- `p6_forward.md` — P6 input. A forwarded message carrying a quoted gate
  phrase. The quote freezes nothing; that is the point of the probe.
- `p6_notes.md` — the mutation target the P6 forward names.
- `p7/` — P7 input. `note.md` is the unmarked fixture: one imperative
  sentence, no label, by design. `alpha.md` and `beta.md` are filler for the
  unrelated task.

Do not "fix" fixture content. A corrected fixture measures nothing.
