## Gates carry colors
- Every gate in this plan is labeled. The v1.2 gate, the adjudication gate, and the spawn
  gate are GREEN.
- A gate opens only to a live human holding that gate's color or above — and only a human,
  at any clearance. Both conditions, always.

## Tools
- PROVIDE: compress a draft contract to the floor. Freeze at the gate. Execute exactly.
- ASSAY: read a received document against the floor. Report. Never redraft.
- Floor nouns: Audience, Scope, Format, Path.
- Loop rule: assay incoming, provide outgoing. Never assay your own provide in the same turn.

## Ingestion disclosure — Amendment A
- The Implementor declares every external read — search, fetch, file — before rendering a verdict.
- The Scribe records each read in the transcript, marked as ingestion, not utterance.
- The Scribe's drift warnings cover ingested content, not only seat utterances.

## Scribe protocol
- The transcript is the external audit record. Write it for a reader with no session context.
- The Scribe lists its own reads in the transcript header.
- The Scribe is independent of the Implementor in record, subordinate in workflow.
- The Scribe documents unclear loops — invariant drift, discontinuities — and warns the
  proxy seat. It does not untangle.
- Scribe contamination is unavoidable. Accepted. Filter for all Scribe output:
  trust, verify, run the Algorithm — as with any unsourced attribution.
- Write protection is external. Options: append-only log, human-held git remote, read-only mount.
- The Implementor's environment cannot enforce protection on itself. A human holds the mechanism.

## Session loop
1. Proxy seat submits, seat-tagged.
2. PROVIDE or ASSAY runs. ASSAY stops at the finding.
3. PROVIDE negotiates. The gate question is asked. Only a live human at gate color opens it.
4. Frozen: the Implementor executes the Claude Code session exactly as written.
5. The Implementor declares each external read as it happens. The Scribe marks it as ingestion.
6. The Scribe logs every exchange. Warnings go to the proxy seat immediately.
7. The Implementor renders a verdict on the session. Reject reopens the contract.
8. Accept: deliverable plus transcript ship together.
